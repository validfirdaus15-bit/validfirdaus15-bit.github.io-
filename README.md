# Valid Firdaus — Portfolio

Website portfolio statis (HTML, CSS, JavaScript vanilla) untuk GitHub Pages.

## Struktur
```
index.html
style.css
script.js
assets/
  Valid_Firdaus_CV.pdf
  images/        (foto profil)
  projects/      (karya desain)
  certificates/  (sertifikat & bukti)
```

## Publikasi ke GitHub Pages
1. Buat repository publik bernama `USERNAME.github.io` (ganti USERNAME dengan username GitHub Anda).
2. Upload semua isi folder ini (bukan folder induknya) ke branch `main`.
3. Buka Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
4. Tunggu 1–2 menit, lalu buka `https://USERNAME.github.io`.

## Catatan
- Ganti foto/karya dengan mengganti file di `assets/` (nama sama).
- Sertifikat baru: tambahkan gambar ke `assets/certificates/` dan satu baris di array `certs` pada `script.js`.
- Jangan unggah data nasabah atau dokumen rahasia ke repository publik.
